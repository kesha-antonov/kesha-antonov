## 🔧 What maintenance looks like

**Gifted Chat went 14 months without a release.** 150,000 people a month kept installing it anyway.
I shipped the next one. Then 25 more.

| | |
|---|---|
| Code that is mine | **76%** - 5,437 lines of 7,176 |
| Commits in the last two years | **85%** - 401 of 471 |
| Commits all time | **404**, more than anyone, including the original author at 303 |
| Backlog when I arrived | **154 issues + 29 PRs**. Now: **3 open issues** |
| Downloads | **168,000 → 444,000/month**, after 30 flat months |

Every React Native release can break native code. Someone ports it before your build fails.
Same for Reanimated, Gesture Handler, Expo SDK, iOS background limits, Android foreground services,
Gradle, AGP, Kotlin. Plus your bug, on a device I don't own, from a stack trace.

None of it ships anything for me. All of it keeps your app building on Monday.

Sponsors get **faster issue turnaround**, **same-week support for new RN and Expo releases**,
